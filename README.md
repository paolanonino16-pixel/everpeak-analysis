# EverPeak Retail Analysis

Este repositório contém a análise realizada durante o Sprint 6 do caso EverPeak–SilverBasket.

O dataset `everpeak_retail` inclui 2.000 pedidos de clientes com valores ausentes, sentinels, outliers e problemas de qualidade criados para simular dados reais do varejo.

## Conteúdo do repositório 📂

- `notebooks/everpeak_analysis.ipynb`
  Notebook principal com limpeza, EDA, distribuições, outliers e conclusões.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](URL_DO_NOTEBOOK_NO_GITHUB)

## Como reproduzir a análise 📘

1. Abra `notebooks/everpeak_analysis.ipynb`.
2. Execute as células em ordem.
3. O notebook carrega automaticamente o dataset a partir de `/data/` ou de um link público, conforme o caso.

## Objetivo da análise 🧠

- Identificar problemas de qualidade dos dados.
- Construir um pipeline de limpeza reproduzível.
- Analisar comportamentos, distribuições e outliers.
- Gerar insights para a equipe de Estratégia e Integração da EverPeak.
